# Clonación de configuración

El owner elige explícitamente servicios, horarios, reglas de reserva, landing, automatizaciones, branding estructural o roles sugeridos. Las copias se vinculan solo al destino y se auditan como `business_configuration_cloned`.

Nunca se clonan clientes, usuarios, membresías, reservas, conversaciones, mensajes, créditos, ledger, integraciones, tokens, incidencias, auditoría, account IDs, media privada ni datos personales del personal. Los roles son sugerencias sin identidad. La media requiere un flujo de copia seguro independiente; esta versión no crea referencias cruzadas.
